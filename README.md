# Research portfolio

I'm Ibrahim, a Data Science graduate from LSE and an MSc Applied Mathematics student at Imperial College London. This repository brings together papers from my academic projects in statistics, machine learning and mathematical modelling.

I created this repository to share the work behind each project: the initial question, the choices involved in developing the theory or building and testing models, and what the results told us.

## Finding your way around

Each project has its own folder with a short README explaining the question, approach and main findings. The full papers will be added alongside these summaries, with more detail on the methods, results and limitations.

## Projects

| Project | What it explores |
| --- | --- |
| [Astronomical Transient Classification](astronomical-transient-classification/) | Comparing attention mechanisms for identifying rare astronomical events in images. |
| [Click-Through-Rate Prediction with AFM–MLP](click-through-rate-prediction/) | Combining attention-weighted feature interactions with a neural network to predict advertisement clicks. |
| [An Introduction to Optimal Transport Theory](optimal-transport/) | The mathematics of moving mass at minimum cost, and the challenges of inferring costs from observed flows. |
| [Continuous-Time State-Space Modelling of NBA Shooting](nba-shooting/) | Modelling changes in shooting form and testing whether they improve next-shot predictions. |

## Code

For the projects that involved coding, I'll add the accompanying code once I've cleaned it up and documented how to run it. The optimal transport dissertation is theoretical and does not include an independent implementation of the computational methods it discusses.
